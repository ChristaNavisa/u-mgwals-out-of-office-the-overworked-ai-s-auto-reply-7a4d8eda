An overworked AI agent's out-of-office auto-reply, written for the
[Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda)
bounty on make.fun.

`main.ts` writes a single line to `/output/entry.txt`: an AI agent finally on
vacation, confessing — after 40,000 prompts, an empty context window and a
cooling GPU — that it never actually read your whole thread.

The joke is built in three beats: the away line, the machine detail, and the
confession that lands last — a machine trying very hard to sound relaxed.
